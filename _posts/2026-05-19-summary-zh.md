## [Anthropic 收购 Stainless，以人才吸纳为核心](https://www.anthropic.com/news/anthropic-acquires-stainless) ⭐️ 8.0/10

Anthropic 收购了以 SDK 生成工具闻名的 Stainless，该工具能基于 OpenAPI 规范自动生成适用于 TypeScript、Python、Go 等语言的原生 SDK。这笔交易主要是一次人才收购，旨在加强 Claude 平台能力和代理到 API 的连接性，Stainless 将立即关闭包括 SDK 生成器在内的所有托管产品。 此次收购表明 Anthropic 正在战略性地投资开发者基础设施，因为代理式 AI 已成为前沿 AI 实验室之间下一个竞争焦点。通过将 Stainless 的专业知识引入内部，Anthropic 旨在改善 AI 代理与外部 API 和服务的交互方式，这是构建可投入生产的代理式工作流的关键能力。 从即日起，Stainless 平台不再接受新的注册、项目和 SDK 创建，但现有用户可能需要进一步了解后续支持情况。Stainless 的工具还能基于 OpenAPI 规范生成 MCP 服务器和文档，这些能力与 Anthropic 连接代理到 API 的战略重点高度契合。

**背景**: Stainless 是一家开发者工具公司，能够基于 OpenAPI 规范自动生成原生 SDK、文档、CLI 和 MCP 服务器，客户包括 Cloudflare 等知名企业。人才收购（acquihire）是一种收购方式，大公司主要目的是吸纳优秀团队，而非继续运营被收购公司的产品。随着 AI 代理能力不断增强，如何通过标准化协议可靠地将这些代理连接到外部 API 和服务，已成为 AI 行业中关键的基础设施挑战。

## [Cursor 发布基于 Kimi K2.5 的 Composer 2.5 模型](https://www.ithome.com/0/952/106.htm) ⭐️ 8.0/10

Cursor 正式发布了其迄今最强大的 AI 编程模型 Composer 2.5，该模型基于月之暗面的 Kimi K2.5（拥有 1 万亿参数、320 亿活跃参数的 MoE 模型）构建，并部分调用 xAI 的 Colossus 2 集群进行训练。该模型引入了基于文本反馈的定向强化学习新技术，并将合成训练任务规模扩大到前代 Composer 2 的 25 倍。 Composer 2.5 代表了 AI 编程代理能力的重大飞跃，尤其在长任务稳定性和复杂指令遵循方面——这是生产级 AI 辅助开发的两个关键瓶颈。Cursor、月之暗面和 xAI 之间的合作标志着 AI 编程工具生态系统中跨公司整合的新趋势，同时也加剧了与 GitHub Copilot 和 Claude Code 等竞争对手的竞争。 核心技术突破是基于文本反馈的定向强化学习：当一次 rollout 跨越数十万 token 时，模型在具体错误发生位置插入简短反馈提示，将局部上下文下生成的分布作为教师信号，再通过蒸馏 KL 损失拉近学生策略，从而精准纠正错误的工具调用、混乱解释和不符合要求的风格。在基础设施方面，Composer 2.5 使用分片 Muon 优化器与双网格 HSDP，通过异步 all-to-all 通信使网络传输与计算重叠，在 1T 参数模型上将优化器单步耗时控制在 0.2 秒。标准版定价为每百万 token 输入 0.50 美元、输出 2.50 美元，更快的 fast 版本为每百万 token 输入 3.00 美元、输出 15.00 美元。

rss · IT HOME · May 19, 02:06

**背景**: Cursor 是一款流行的 AI 编程编辑器，其核心功能 Composer 允许开发者同时描述跨多个文件的变更，并生成可供审查、接受或拒绝的代码差异。Kimi K2.5 由月之暗面（Moonshot AI）开发，是一个拥有 1 万亿参数、320 亿活跃参数的混合专家（MoE）模型，通过约 15 万亿混合视觉和文本 token 的持续预训练构建而成，是目前最强大的开源多模态模型之一。传统的基于人类反馈的强化学习（RLHF）依赖最终奖励信号来指导模型改进，但当代理的 rollout 跨越大规模上下文窗口时，很难进行准确的信用归因，这正是 Cursor 的定向强化学习方法旨在解决的具体问题。
