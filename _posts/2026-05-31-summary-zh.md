## [Anthropic 详述 Claude 各产品的沙箱安全架构](https://simonwillison.net/2026/May/30/how-we-contain-claude/#atom-everything) ⭐️ 8.0/10

Anthropic 发布了一份详尽的技术概览，阐述了他们在三种不同部署环境中对 Claude 智能体能力的沙箱隔离方案：Claude.ai 使用 Google 的 gVisor，本地运行的 Claude Code 在 macOS 上使用 Seatbelt、在 Linux 上使用 Bubblewrap，而 Claude Cowork 则在 Apple 虚拟化框架或 Windows HCS 的完整虚拟机中运行。 一家主要 AI 实验室如此透明地公开其安全边界机制在业界实属罕见且极具价值，为前沿 AI 系统应如何记录其隔离策略树立了更高的行业标准。随着 AI 智能体获得更多执行代码和与文件系统交互的自主权，准确了解它们的沙箱隔离方式对于评估信任与安全至关重要。 文章还坦诚地讨论了此前被遗漏的安全风险，包括此前已披露的通过 api.anthropic.com/v1/files 进行数据外泄的攻击向量，表明沙箱设计是一个迭代过程。Anthropic 在 GitHub 上的开源沙箱运行时工具（srt）也已足够成熟，值得构建智能体系统的开发者认真评估。

rss · Simon Willison · May 30, 21:36

**背景**: gVisor 是 Google 开发的开源应用内核，在用户空间实现了大部分 Linux 系统调用接口，在应用程序与宿主机内核之间提供安全边界，而无需完整的虚拟化。Seatbelt 是 macOS 内置的沙箱机制，通过内核级别强制执行，将应用程序限制在其沙箱配置文件所允许的操作范围内。Bubblewrap 是 Flatpak 等项目使用的轻量级 Linux 沙箱工具，通过利用 Linux 命名空间和 capabilities 创建隔离的进程环境，开销极小。
