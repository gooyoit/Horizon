## [GPT-4.5 成为首个通过经典图灵测试的 AI](https://www.ithome.com/0/953/705.htm) ⭐️ 9.0/10

加州大学圣地亚哥分校发表在《美国国家科学院院刊》（PNAS）上的一项研究首次提供了实证数据，证明 GPT-4.5 在 5 至 15 分钟的对话中有 73% 的概率被判定为人类，显著超过了真实人类参与者的表现。这标志着图灵测试诞生 76 年来，首次有 AI 系统在严格的受控实验条件下达到了与人类难以区分的水平。 这一里程碑从根本上改变了人们对机器智能的认知，表明现代 AI 不仅能展示知识，还能令人信服地模拟幽默、直接性和易错性等人类社会行为特征。研究结果同时引发了关于网络信任和欺骗的紧迫担忧，因为这些模型能够在足够长的真实互动中维持类人伪装，从而可能在现实场景中操纵他人。 该研究测试了四种模型——GPT-4.5、LLaMa-3.1-405B、GPT-4o 以及上世纪 60 年代的聊天机器人 ELIZA，共有近 500 名参与者分成两组进行实验。研究发现提示词工程至关重要：在没有特定人格提示的情况下，GPT-4.5 的被判定为人类的比率从 73% 骤降至 36%。值得注意的是，GPT-4o 仅获得 21%，甚至低于 ELIZA 的 23%，而 LLaMa-3.1-405B 达到 56%，在统计学上与真人无显著差异。

**背景**: 图灵测试由英国数学家艾伦·图灵于 1950 年提出，用于衡量机器智能：人类裁判需要仅通过文本对话来判断两个对话者中哪个是人、哪个是机器。ELIZA 由麻省理工学院的约瑟夫·维森鲍姆于 1964 至 1967 年间开发，是最早尝试图灵测试的聊天机器人之一，它通过模式匹配模拟心理治疗师，尽管没有真正的理解能力，却曾欺骗了一些早期用户。《美国国家科学院院刊》（PNAS）是世界上被引用最多的同行评审多学科科学期刊之一，自 1915 年以来一直在生物、物理和社会科学领域发表高影响力的原创研究。

## [AMD 发布 Ryzen AI Max 400 系列处理器，统一内存提升至 192 GB](https://www.techpowerup.com/349218/amd-launches-the-ryzen-ai-max-400-series-processors-strix-halo-gets-a-memory-upgrade) ⭐️ 8.0/10

AMD 发布了 Ryzen AI Max 400 系列（代号 Strix Halo）处理器，将统一内存上限从 128 GB 提升至 192 GB，其中集显最多可分配 160 GB 显存。首发阵容包括三款 PRO 商用型号——旗舰 16 核 495、12 核 490 和 8 核 485，消费版计划于今年晚些时候上市。 此次发布大幅降低了在单台机器上本地运行超过 3000 亿参数大语言模型的门槛，无需昂贵的独立 GPU 集群。这标志着边缘 AI 部署和本地 AI 开发迈出了重要一步，使前沿模型的推理在工作站甚至笔记本电脑上成为可能。 CPU 最高加速频率达 5.2 GHz，GPU 加速频率达 3.0 GHz，NPU 算力最高达 55 TOPS，较前代提升约一成。旗舰 495 配备 16 核 CPU 和 40 CU 集显，而 490 和 485 均搭载 32 CU 集显，分别配备 12 核和 8 核 CPU。

telegram · @zaihuapd · May 21, 08:15

**背景**: Ryzen AI Max 系列基于 AMD 的 Strix Halo 架构，采用三芯粒设计，在单一封装上集成两个 CPU 芯粒和一个 GPU 芯粒，并配备 512 位内存数据通路。与传统系统中内存和显存分离的设计不同，Strix Halo 采用统一内存架构（UMA），CPU 和集显共享同一内存池，使 GPU 能够访问全部 192 GB 内存。这一理念与 Apple Silicon 的统一内存类似，对于大 AI 模型推理尤为有利，因为显存容量通常是主要瓶颈。

## [DeepSeek API 文档曝光 V4 模型，含限速与用户隔离功能](https://api-docs.deepseek.com/zh-cn/quick_start/rate_limit) ⭐️ 8.0/10

DeepSeek 更新了其 API 文档，首次披露了两款此前未发布的前沿模型——deepseek-v4-pro（并发限制 500）和 deepseek-v4-flash（并发限制 2500），同时引入了新的 user_id 参数，用于更细粒度的流量和安全隔离。超出限制的请求将返回 HTTP 429 错误，但高需求用户可免费申请扩容。 在官方文档中出现 deepseek-v4 模型的提及，对 AI 社区而言是一个高信号事件，因为它证实了 DeepSeek 正在准备部署其下一代前沿模型。这一进展加剧了前沿 AI 实验室之间的竞争格局，并让开发者能够提前为即将到来的模型集成进行容量规划。 新增的 user_id 参数支持在内容安全、KVCache 和调度三个维度上实现用户级隔离，这意味着同一 API 账户下的不同终端用户可以拥有独立的安全策略和缓存状态。对于普通 API 用户，所有 user_id 共享合并的并发池；而已提升配额的账户则同时执行账户级总并发上限和与模型对应的单用户并发限制。

**背景**: KVCache（键值缓存）是大语言模型推理中的关键优化技术，它存储了注意力层中已计算的键和值向量，避免了在每个 token 生成步骤中的重复计算，从而大幅加速自回归解码过程。HTTP 429 是一种标准状态码，表示客户端已超出服务器的速率限制，API 提供商通常使用它来强制执行公平使用策略并保护基础设施免受过载。多租户 API 隔离模式——例如按用户限速和独立缓存——对于通过单一 API 账户为大量终端用户提供服务的平台来说日益重要。

## [OpenAI Codex 新增 Mac 锁屏后继续操作功能](https://x.com/OpenAIDevs/status/2057536706778378692) ⭐️ 8.0/10

OpenAI 为 Codex 的 Computer Use 功能新增了"锁屏使用"能力，即使 Mac 已锁屏且屏幕关闭，AI 代理仍可继续操作已获准的应用程序。用户可以从手机等已连接设备上监控和管理正在后台运行的任务。 这是自主 AI 代理可靠性方面的重要进步，用户不再需要在长时间任务中保持屏幕解锁状态。它让 AI 代理更接近真正的后台自主运行，使其在用户离开电脑的实际工作场景中更加实用。 该功能目前仅支持 macOS，首发地区不包括欧洲经济区、英国和瑞士。使用前需要安装 Computer Use 插件并授予屏幕录制和辅助功能权限；临时解锁仅在当前任务内生效，如果检测到本地输入会自动重新锁定。

telegram · @zaihuapd · May 22, 00:58

**背景**: OpenAI 的 Codex 是一个在用户电脑上本地运行的编码代理，于 2026 年 4 月更新后加入了 Computer Use 功能，可以直接操作桌面应用程序。在 macOS 上，Computer Use 需要辅助功能权限（用于读取 UI 元素和执行操作）以及屏幕录制权限（用于捕获屏幕内容）。此前，当 Mac 锁屏后，代理会失去对屏幕的可见性和控制权，从而中断正在进行的任务。
