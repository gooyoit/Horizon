## [Qwen 发布 3.8-Max：2.4 万亿参数开源模型](https://t.me/zaihuapd/43151) ⭐️ 10.0/10

阿里巴巴通义千问团队正式发布 Qwen 3.8-Max，该模型基于 Qwen 3.5 架构构建，总参数量达 2.4 万亿，活跃参数为 950 亿。模型权重将于下周开源，这是 Qwen 首次对 Max 级别模型开放权重。 开源一个拥有 2.4 万亿参数的 Max 级前沿模型，标志着开源 AI 社区的重大飞跃，有望在编码、智能体任务和长上下文推理方面匹敌顶级闭源模型。这表明超大规模的混合专家模型也能被用于研究和商业用途，进一步加剧了与 Kimi 等开源竞品以及闭源模型的竞争。 该模型采用混合专家架构，总参数量为 2.4 万亿，但每个 token 仅激活 950 亿个参数，这使得推理在计算上更加高效，尽管内存占用量依然庞大。完整的 BF16 精度模型需要约 4.9TB 内存，1-bit 量化可将其降至约 397GB；此外，开放权重的版本缺少视觉输入支持以及官方 API 版本默认提供的 100 万 tokens 上下文长度。

telegram · @zaihuapd · Aug 12, 16:13

**背景**: 混合专家是一种架构，模型拥有庞大的总参数量，但每个 token 仅激活一部分专家子网络，这使得其计算成本低但内存需求大。FP8 和 1-bit 等量化技术通过降低模型权重的精度来减小模型体积和内存需求，使其能够在更易获取的硬件上部署。智能体 AI 是指能够半自主地进行规划、使用工具并以最少的人工监督执行多步骤任务的系统。

Unsloth AI 发布了 Unsloth Desktop，这是一个无代码的 Web UI 界面，允许用户完全在个人电脑上训练、运行和导出开源大语言模型（LLM）。该工具将整个本地 AI 工作流整合到一个统一的桌面界面中，无需复杂的命令行配置或云服务。 这款工具的发布大大降低了开发者和研究人员的使用门槛，使他们能够在不产生云计算成本或损害数据隐私的前提下定制开源模型。通过为一个已实现训练速度提升 30 倍、内存使用减少 90% 的框架提供完善的图形界面，它让高效的本地微调变得更加大众化。 Unsloth Desktop 作为一个统一的本地界面，将强大的 Unsloth Python 库封装在一个易于使用的无代码环境中。它支持完整的模型生命周期，允许用户直接在桌面上管理从初始训练、微调到推理和模型导出的所有操作。

producthunt · Zac Zuo · Aug 12, 03:47

**背景**: 微调是指将预训练的大语言模型在特定的、较小的数据集上进一步训练，使其适应专门的任务或掌握专有知识的过程。传统上，这一过程需要大量的计算资源，通常外包给云平台，这引发了关于成本和数据隐私的担忧。Unsloth 是一个开源的 Python 库，它在数学和硬件层面对该过程进行了优化，大幅降低了所需的 VRAM 并加快了本地环境的训练速度。
