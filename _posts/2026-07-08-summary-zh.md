## [Anthropic 开发者分享 Advisor 与 Orchestrator 两种多智能体模式](https://aihot.virxact.com/items/cmrbdqlcv02y4ihl11xbxx9xs) ⭐️ 9.0/10

Anthropic 开发者官方分享了两种高频使用的多智能体模式：Advisor 模式由 Sonnet 执行者调用更强大的模型获取指导，Orchestrator 模式则由强大的模型作为编排者向多个 worker 智能体分发任务。在 SWE-bench Pro 和 BrowseComp 基准测试中，这些组合方案达到了最强单独模型 92%至 96%的性能，同时将推理成本降低了约 37%至 54%。 这些模式通过策略性地混合不同能力和价格的模型，展示了一种实用且高性价比的生产级 AI 智能体构建蓝图。对于需要在接近最先进性能与可持续推理成本之间取得平衡的 AI 工程师和开发者来说，这具有极高的参考价值。 在 SWE-bench Pro 的 Advisor 模式中，Sonnet 加顾问的组合以每题 1.40 美元的成本达到了 84%的准确率，而顾问模型单独运行为 91.5%准确率、成本 2.25 美元。在 BrowseComp 的 Orchestrator 模式中，使用强大模型编排 Sonnet worker 的方案以 18.53 美元获得了 86.8%的得分，接近全强大模型配置 90.8%的得分（成本高达 40.56 美元）。

## [NVIDIA 发布 Audex 统一音频-文本 MoE 大语言模型](https://aihot.virxact.com/items/cmrbd7yfd02uyihl1bjh4eibd) ⭐️ 9.0/10

NVIDIA 发布了 Audex（Nemotron-Labs-Audex-30B-A3B），这是一个基于 30B-A3B 混合专家架构的统一音频-文本大语言模型，能够处理并生成音频与语音，同时保持强大的文本智能。该模型支持 1M token 的上下文窗口，并在多项基准测试中取得最优结果，包括在 OpenASR 中达到 6.82 的词错误率，优于 Step-Audio-R1.1-33B 和 Qwen3-Omni-30B-A3B-Thinking 等竞品。 此次发布代表了多模态 AI 领域的重大进展，证明了可以在不损害大语言模型核心文本推理能力的前提下为其增加音频处理功能。通过将音频与文本处理统一并结合超长上下文窗口，Audex 为实时语音助手、转录服务和多模态智能体工作流开辟了新的可能性。 Audex 采用混合专家 Transformer 解码器，总参数量为 30B 但每 token 仅激活 3B，训练过程使用了多阶段 SFT 加文本专用 Cascade RL，以避免多模态文本智能退化。模型权重（包括较小的 Audex-2B 版本）以非商业许可发布。

## [蚂蚁集团周俊：从 Token 数量到 Token 密度，万亿参数模型效率优先](https://aihot.virxact.com/items/cmrbdsefa02yjihl17gg7mhx3) ⭐️ 8.0/10

蚂蚁集团副总裁周俊在 AICon 上揭示了万亿参数模型从"更多 Token"转向"更高 Token 密度"的策略，采用 7 份 Lightning Attention 加 1 份 MLA 的混合线性注意力架构。该方案将 256K 长上下文推理成本从指数级降至线性级，同时通过 Kpop Token 掩蔽算法及思维链剪枝等技术，在能力不降的前提下将 Token 输出减少约 4 倍。 万亿参数模型每运行 15 分钟的算力成本约等于一辆特斯拉，效率已成为 AI 智能体时代最关键的瓶颈。这些架构和算法优化使千亿参数模型在 Agent 任务中超越部分更大模型，同时小模型实现 2.4 倍吞吐提升和多轮对话成本下降 10 倍以上。 混合注意力架构采用 Lightning Attention-2——一种硬件感知的线性注意力机制，通过解耦块内和块间计算实现线性时间和常数内存，并结合 MLA 将键值投影压缩为潜在表示以减小 KV 缓存。Kpop 算法是一种双向二元 KL 散度 Token 掩蔽策略，通过区分工具调用 Token 和自然语言 Token 来优化训练效率。
