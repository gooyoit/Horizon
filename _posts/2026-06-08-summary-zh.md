## [研究发现 AGENTS.md 文件反而降低编码 Agent 成功率](https://x.com/shao__meng/status/2063790077021753383) ⭐️ 8.0/10

一项大规模实证研究（arxiv.org/abs/2602.11988）在 SWE-bench Lite（300 任务）和新建的 AGENTBENCH（138 任务）上测试了 Claude Code、Codex 和 Qwen Code 等编码 Agent，发现 LLM 自动生成的上下文文件在 8 组设置中有 5 组成功率下降，SWE-bench 平均下降 0.5%，AGENTBENCH 平均下降 2%，同时成本增加超过 20%。 这项研究挑战了业界日益增长的假设——即添加 AGENTS.md 文件就能自动提升编码 Agent 的表现，揭示了臃肿或冗余的上下文反而会损害结果。这些发现为 AI 工程团队如何有效配置仓库级指令提供了可操作的建议。 开发者手写的上下文文件仅带来平均 +4% 的微弱提升；冗余假说得到验证：当移除其他文档后，自动生成的文件反而提升了 +2.7% 的表现，说明与已有文档的重叠会导致混淆。论文建议避免自动生成、精简测试和 lint 命令，并优先编写仓库专用的工具文档。
