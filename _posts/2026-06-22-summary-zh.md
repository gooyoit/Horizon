## [前 Meta/Microsoft 主任工程师分享每日交付 40-50 个 PR 的 Agentic 工程工作流](https://aihot.virxact.com/items/cmqohj2u8013jslx6nfiz7tyn) ⭐️ 8.0/10

kunchenguid，前 Meta 和 Microsoft 主任工程师，发布了一段 45 分钟的视频，详细讲解了一个四层 Agentic 工程工作流，能够每天交付 40-50 个生产级 PR。该工作流涵盖终端中心环境配置、使用精简全局 memory 的 agent 入职流程、用于高效 agent 工具交互的 AXI 标准，以及由名为 First Mate 的元 agent 调度的对抗式验证流水线。 这一工作流代表了高级工程师如何通过编排 AI agent 而非仅仅将其作为编码助手来实现极致生产力提升的前沿范例。此处引入的 AXI 标准声称能大幅降低 token 消耗和延迟，直接挑战了 MCP，可能影响整个行业设计 agent 与工具交互接口的方式。 AXI 标准基于 10 条设计原则构建，将 token 预算视为一等约束，据报道比 MCP 少消耗 3 倍 token 和 2 倍延迟。该工作流使用 treehouse 管理一组可复用的隔离 git worktree，使每个并行 agent 能即时获得自己的环境，同时 no-mistakes 流水线在任何 PR 合并之前在隔离环境中运行对抗式审查和 E2E 测试。

rss · AI Hot · Jun 22, 00:35

**背景**: MCP（Model Context Protocol）是一个开放标准，定义了应用程序如何与 LLM 共享上下文，通过 JSON-RPC 提供了一种将 AI 模型连接到外部数据源和工具的标准化方式。Git worktree 允许在独立目录中同时检出多个分支，实现无克隆冲突的并行开发。AXI（Agent eXperience Interface）是一种更新的范式，提出从零开始为 token 效率设计的 agent 原生 CLI 工具，定位为 MCP 和传统 CLI 方法的替代方案。

## [鸿海：1GW 英伟达 Vera Rubin AI 数据中心需耗资 470 亿美元](https://www.ithome.com/0/966/801.htm) ⭐️ 8.0/10

鸿海董事长刘扬伟透露，基于英伟达即将推出的 Vera Rubin 平台建设 1GW 规模的 AI 数据中心需要约 470 亿美元的资本支出，每年电力成本高达 13 亿美元。单个 Vera Rubin 机架售价达 910 万美元，1GW 数据中心总共需要约 3557 个各类机架。 这些数字罕见地揭示了下一代前沿 AI 基础设施惊人的资本和运营成本，意味着只有全球最大的科技巨头和主权国家才能负担得起此类设施。这些数据也表明，电力供应和能源成本正成为与芯片本身同样关键的扩展 AI 算力的瓶颈。 每个 Vera Rubin NVL72 机架集成了 72 个 Rubin GPU 和 36 个 Vera CPU，采用液冷散热，提供 3.6 EFLOPS 的 NVFP4 推理算力和 2.5 EFLOPS 的训练算力。硬件折旧费用是年度电力成本的六倍，该平台预计将于 2026 年下半年通过合作伙伴供货。

rss · IT HOME · Jun 22, 02:21

**背景**: 英伟达的 Vera Rubin 平台在 GTC 2026 上发布，是该公司面向智能体 AI 和大规模推理工作负载的下一代 AI 数据中心架构，接替 Blackwell 架构。该平台的旗舰机架级产品 Vera Rubin NVL72 基于第三代 MGX 机架设计，声称推理成本较上一代降低至十分之一。全球数据中心电力容量预计将从 2024 年的 68GW 飙升至 2030 年的 174GW，主要受 AI 模型开发商、云服务商、政府和企业对算力的巨大需求驱动。
