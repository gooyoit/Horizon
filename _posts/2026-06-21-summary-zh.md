## [思科 AI 发布 FAPO：基于 Claude Code 的多步 LLM 流水线优化系统](https://www.marktechpost.com/2026/06/20/cisco-ai-introduces-fapo-pipeline-aware-prompt-optimization-with-step-level-failure-attribution-and-claude-code-orchestration) ⭐️ 8.0/10

思科 AI 基于 Apache 2.0 协议开源了 FAPO，这是一个由 Claude Code 驱动的多步 LLM 流水线自动化优化系统，通过步骤级故障归因进行优化。在与 SOTA 优化器 GEPA 的基准对比中，FAPO 使用 GPT-4.1-mini、GPT-5.4-mini 和 Gemma 3-12B 作为任务模型，在 18 个模型-基准比较中赢下 15 个，平均增益达 +14.1 个百分点。 FAPO 引入了一种全新的流水线感知方法，将优化从提示词和参数逐级升级到链式结构，推动了自动化 LLM 编排的边界。它对当前 SOTA 优化器的显著超越，证明了在使复杂的多步 LLM 工作流更可靠和自我纠正方面取得了重大飞跃。 FAPO 在 HoVer 和 IFBench 上触发结构升级时六组全胜，平均增益高达 +33.8 个百分点；但在 AIME 上略逊 3.1 个百分点，处于采样噪声范围内。防过拟合机制包括仅检查训练集、使用不可变文件以及进行独立审查。

rss · AI Hot · Jun 20, 23:04

**背景**: 多步 LLM 流水线将多个语言模型调用串联以解决复杂任务，但任何单个步骤的失败都可能导致连锁反应并降低整体输出质量。传统的提示词优化器（如 GEPA）主要侧重于孤立地优化单个提示词，而不会诊断具体是哪个步骤导致了流水线故障。步骤级故障归因是一种诊断技术，能够隔离并识别链式工作流中的确切瓶颈，从而实现有针对性的结构和提示词级别的修正。
