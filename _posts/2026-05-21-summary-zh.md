## [Chrome DevTools for Agents 1.0 正式发布](https://x.com/shao__meng/status/2057262293348679733) ⭐️ 8.0/10

Chrome DevTools for Agents 1.0 已正式发布，使 AI Agent 能够在真实的 Chrome 浏览器实例中自主观察、调试和测试 Web 应用。该工具支持 MCP server、CLI 和 Agent skills 三种集成方式，并预装在 Antigravity 2.0 中，可立即使用。 此次发布标志着自主编程和基于 Web 的 AI Agent 迈出了重要一步，Agent 现在可以执行 Lighthouse 审计、检测内存泄漏、调试 Chrome 扩展以及接管已登录会话等任务——这些能力此前只能由人类开发者完成。它弥合了 AI 编程助手与真实浏览器环境之间的鸿沟，大幅提升了自动化开发和测试工作流的效率。 Agent 可以通过 Lighthouse 执行自动化质量审计、模拟用户环境、调试 Chrome 扩展、接管已登录会话、检测内存泄漏，并与 Web 应用暴露的内部状态深度集成。该工具以 npm 包的形式分发，作为 MCP server 运行，通过 Chrome 自身的 DevTools 协议将 AI 编程助手直接连接到实时 Chrome 实例。

rss · AI Hot · May 21, 00:48

**背景**: 模型上下文协议（MCP）是 Anthropic 于 2024 年 11 月推出的开放标准，旨在标准化 AI 系统与外部工具、系统和数据源的集成方式。MCP server 通过标准化协议接口向 AI 应用暴露特定能力——例如用于文档访问的文件系统服务器或用于数据查询的数据库服务器。Chrome DevTools 是 Chrome 内置的开发者工具包，允许开发者检查、调试和分析网页，而此次发布本质上是通过 MCP 标准将这些能力开放给 AI Agent。
